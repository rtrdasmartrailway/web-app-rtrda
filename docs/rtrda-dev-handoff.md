# ส่งต่องาน Dev ของ RTRDA

- งาน Dev นี้รับคำสั่งจากเจ้าของเท่านั้น (owner-only): แก้เฉพาะขอบเขตที่ได้รับมอบหมายในพื้นที่ทำงานแยก ไม่แตะข้อมูลลับหรือระบบ Production
- ทำงานบน branch แยก ตรวจสถานะ Git ก่อนแก้ไข รักษาการเปลี่ยนแปลงอื่นไว้ และรันการทดสอบที่เกี่ยวข้องในสภาพแวดล้อมแยก ส่งผลทดสอบและรายการไฟล์ให้ผู้ดูแลรับช่วงต่อเพื่อพิจารณา Draft PR/Test; การผ่านการทดสอบในพื้นที่ทำงานไม่ใช่การยืนยันว่า deploy แล้ว
- ห้าม merge หรือ deploy Production อัตโนมัติ การขึ้น Production ต้องได้รับการอนุมัติอย่างชัดเจนจากเจ้าของสำหรับ release/SHA ที่ระบุ และดำเนินการโดยผู้รับผิดชอบตามกระบวนการ release แยกต่างหาก
